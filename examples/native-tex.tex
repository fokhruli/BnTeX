\section*{BnTeX: native Bengali in pdfLaTeX}
This example uses a reusable font installation, not a prepared-word cache.
Edit the Bengali text below and compile again with pdfLaTeX only.

ব্যবহার এবং শিক্ষার্থীদের গবেষণার বিষয় উঠে এসেছে।}
